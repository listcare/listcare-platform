# ListCare MVP

Customer-facing εφαρμογή για ιδιοκτήτες και διαχειριστές καταλυμάτων.

## Περιλαμβάνει

- Εγγραφή/σύνδεση με email και κωδικό.
- Αποθήκευση πολλών καταλυμάτων ανά χρήστη.
- Υπόλοιπο και ιστορικό credits.
- Καταχώρηση: έλεγχος, τίτλοι και περιγραφές.
- Φωτογραφίες: προτεινόμενη σειρά και ασφαλής βελτίωση φωτισμού/ευκρίνειας.
- Τιμές & κέρδος: καθαρό αποτέλεσμα και προτάσεις τιμών.
- Κριτικές: ανάλυση και έτοιμες απαντήσεις.
- Demo κατάλυμα: Villa Theona.

## Οικονομικό μοντέλο MVP

- Δωρεάν εγγραφή: 6 credits.
- Starter: 25 credits / 9,90€.
- Plus: 70 credits / 19,90€.
- Pro: 180 credits / 39,90€.
- Δεν λήγουν και δεν υπάρχει συνδρομή στο MVP.

## Ρόλοι υπηρεσιών

- Shopify: marketing, πακέτα credits και checkout.
- Supabase: λογαριασμοί, καταλύματα, αρχεία και ledger credits.
- OpenAI Responses API: κείμενο, vision, ανάλυση και web research.
- Sharp: βελτίωση φωτογραφίας χωρίς γενετική αλλαγή αντικειμένων.

## Εκκίνηση

1. Δημιούργησε Supabase project και εκτέλεσε το `supabase/schema.sql`.
2. Αντέγραψε `.env.example` σε `.env.local` και συμπλήρωσε τα secrets.
3. Εκτέλεσε `npm install` και `npm run dev`.

Μην αποθηκεύεις API keys στον κώδικα ή σε συνομιλίες.
